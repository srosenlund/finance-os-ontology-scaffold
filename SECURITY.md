# Security policy

Se den fulde danske guide: [`docs/SECURITY.md`](docs/SECURITY.md).

## Rapporter sårbarheder

Rapportér sikkerhedsproblemer privat via GitHub **Security → Advisories → New draft security advisory** på dette repo, eller skriv til repository-ejeren.

Paste ikke tokens, CPR, IBAN eller kontoudtog i issues.

## Secrets i git

Dette repo er et offentligt POC-scaffold. Live credentials, `local/bank-view.json`, PDF’er og `taxonomy/sot-map.json` skal forblive gitignoreret.
